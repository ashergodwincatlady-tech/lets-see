# PYN expanded Python course

Run with `python -m http.server 8000` and open http://localhost:8000.

Changes: next-lesson navigation; 255 original lessons and practice stops in 10 sections; searchable section and unit path; simple-word glossary; VS Code download link; checked lesson questions; code and downloads for all 12 projects; saved custom projects; five color themes; SVG avatar editor and seven accessory options; removal of simulated members and teaching videos.

Progress, projects, and video drafts remain local to the device. No live accounts, database, moderation service, or shared community activity is connected. Lesson completion verifies a knowledge question; practice code is run in VS Code and is not executed or graded by this app. Project completion is self-reported. AI project code requires credentials and may incur API costs.

To deploy, replace index.html, app.js and styles.css and add course.js in the GitHub repository linked to Vercel, then commit the changes. This package has not been pushed or deployed. COURSE-COVERAGE.md lists the scope and every source topic. NumPy, Pandas, SciPy, and Django have introductory lessons corresponding to their main-menu links; their separate full courses are not reproduced.
